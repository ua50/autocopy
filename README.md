# AutoCopy

Виділив текст мишкою — і він уже в буфері обміну. Для **Windows** і **macOS**.

**Завантажити:** [Releases](https://github.com/ua50/autocopy/releases) — `AutoCopy.exe` для Windows, `.dmg` для Mac.

## Що вміє

- Протягнув мишкою або двічі/тричі клацнув по тексту — текст скопійовано (програма сама натискає Ctrl+C / Cmd+C).
- Тихий звук і підказка «✓ Скопійовано» (вимикаються в меню).
- **Два останні скопійовані тексти** тримає в пам'яті:
  - **Ctrl+Alt+V** (Windows) / **Ctrl+Option+V** (Mac) — меню «1 / 2» біля курсора, вибране вставляється;
  - правий клік над текстом — поруч зі стандартним меню з'являється панель «1 / 2».
- «Де не копіювати…» — список програм, де автокопіювання вимкнене (термінали, Excel, Провідник/Finder, віддалені робочі столи…).
- Не копіює в полях паролів і не запам'ятовує паролі з менеджерів паролів.
- «Перевірити оновлення…» у меню порівнює вашу версію з останньою в [Releases](https://github.com/ua50/autocopy/releases) і пропонує відкрити сторінку завантаження. Нічого не завантажує й не встановлює сама.
- Скопійоване нікуди не передається і не пишеться на диск (на диску лише файл налаштувань). В інтернет програма звертається тільки тоді, коли ви натиснете «Перевірити оновлення»: запит до GitHub містить лише назву програми й версію.

## Встановлення

### Windows 10/11
1. Завантажте `AutoCopy.exe` і покладіть у будь-яку теку (поруч з'явиться `settings.txt`).
2. Запустіть. Значок «A» з'явиться біля годинника.
3. Автозапуск: значок → «Запускати разом з Windows».

Windows SmartScreen може попередити про невідомого видавця: «Докладніше» → «Виконати в будь-якому разі».

### macOS 13+
1. Відкрийте `.dmg` і перетягніть **AutoCopy** на **Applications**.
2. Перший запуск: правий клік по AutoCopy → «Відкрити» → «Відкрити» (програма не нотаризована Apple).
3. Дайте дозвіл: «Системні параметри → Конфіденційність і безпека → Універсальний доступ» → увімкніть AutoCopy.
4. Автозапуск: значок «A» у верхньому меню → «Запускати разом з Mac».

Після оновлення програми macOS може забути дозвіл: видаліть AutoCopy зі списку «Універсальний доступ» кнопкою «−» і додайте знову «+».

## Збирання з коду

- **Windows:** `build.cmd` — використовує `csc.exe`, вбудований у Windows (.NET Framework 4.8), SDK не потрібен. Код: `AutoCopy.cs`.
- **macOS:** `mac/build.sh` — потрібні Xcode Command Line Tools (`swiftc`). Код: `mac/AutoCopy.swift`. `./build.sh --no-install` лише збирає `.app` і `.dmg`.

---

**English:** AutoCopy copies selected text to the clipboard automatically (Windows and macOS), keeps the last two copied texts in memory (Ctrl+Alt+V / Ctrl+Option+V or a panel next to the right-click menu) and never stores or sends them anywhere. Download from Releases.
